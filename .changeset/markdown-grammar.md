Markdown read more fully: links and images in parts (brackets, the text, the address, the title) and nested — a badge, an image in a link, whole; references `[text][ref]` and their definitions, footnotes `[^1]`, bare and angle-bracket addresses; the quoted text in a colour of its own; a heading's marker apart from its text; strike-through; tables' bars and rule rows; task boxes; inline HTML as HTML; YAML front matter. A line starting with inline code in backticks (```` ```x ````) is no longer taken for a fence; an underscore inside a word is not emphasis.
